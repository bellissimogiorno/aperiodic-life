## Matters not decided

No choice of a new search horizon, new rule family, Spectre geometry implementation, GPU simulation backend, publication venue or new application version is implied by this handover. These remain implementation/research proposals, subject to evidence and the user's next priorities. The unresolved proof of indefinite Einstein propagation is a research problem, not an outstanding routine bug fix.

## 15 October 2026 maintenance decisions

- **DEC-21 — Randomise and replay:** Randomise/R creates a fresh seed and applies it. Apply seed/Enter repeats a chosen seed. Keep deterministic startup, geometry rebuilds and curated examples so that reproducibility remains explicit.
- **DEC-22 — Reviewed catalogue:** preserve the existing PDF, Markdown, structured data, geometry and evidence bytes. Record catalogue version separately from the application version, including embedded download names. No scientific catalogue revision is needed for this control fix.
- **DEC-23 — Verification:** run the available simulation, topology, large-patch, interaction and packaging checks; record unavailable browser prerequisites as limitations, not passes. Preserve earlier dated evidence as historical evidence.

- **DEC-24 — Canvas keyboard navigation:** arrow keys pan the viewed area in the named direction only while the canvas has focus; each step is 40 CSS pixels, or 120 with Shift. A click or Tab focuses the canvas. Manual keyboard panning disables automatic discovery framing like other manual navigation. Form controls and modal dialogs keep their keyboard behaviour.
